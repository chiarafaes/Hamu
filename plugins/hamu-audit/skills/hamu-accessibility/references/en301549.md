# EN 301 549

## Versions

| Version | Date | WCAG basis | Status |
|---|---|---|---|
| v3.2.1 | March 2021 | 2.1 A and AA | Harmonised for the Web Accessibility Directive (Implementing Decision (EU) 2021/1339). Used as the presumption of conformity for the EAA until a newer version is cited in the Official Journal. |
| v4.1.1 | Published September 2026 (reported adoption August 2026) | 2.2 A and AA | Adds an annex mapping EAA essential requirements to clauses. Presumption of conformity starts only after the Commission cites it in the Official Journal (verify status before each run). |

Hamu tests WCAG 2.2 AA, which meets both versions for web content. A finding on a criterion new in 2.2 maps to EN301549 only as v4.1.1, and the report says so.

## Clauses the skill uses

| Clause | Scope | Mapping |
|---|---|---|
| 5 | Generic requirements (closed functionality, biometrics, preservation of accessibility information) | manual, rarely relevant for web |
| 6 | ICT with two-way voice communication (real-time text) | only for calling or chat-with-voice services |
| 7 | ICT with video capabilities (captions, audio description handling in players) | A11Y.MEDIA.* when the site has its own player |
| 9 | Web content: clause `9.x.x.x` equals WCAG SC `x.x.x` | all web checks |
| 10 | Non-web documents (PDF, Office): clause `10.x.x.x` follows WCAG with adapted wording | A11Y.DOC.* |
| 11 | Software, including native mobile apps: clause `11.x.x.x` follows WCAG, plus 11.5 interoperability with assistive technology and 11.7 user preferences | A11Y.MOBILE.* |
| 12 | Documentation and support services: accessible product documentation, support services that can communicate in accessible ways | A11Y.STATEMENT.FEEDBACK |

## Beyond WCAG

Meeting WCAG 2.2 AA is not full EN 301 549 conformance. Clauses 5, 6, 7, 11.5 to 11.8 and 12 add requirements. The report lists them as `needs_manual` when the product has those features.
