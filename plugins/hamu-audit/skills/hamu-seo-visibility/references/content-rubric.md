# Content rubric

Score 2 = pass, 1 = warn, 0 = fail. Pick the closest example. Quote or screenshot the evidence.

| Check | 2 | 1 | 0 |
|---|---|---|---|
| SEO.I18N.TRANSLATED | Every language version fully translated, including title, meta, alt and schema. | Body translated, some meta or UI strings in another language. | Mixed languages on the page, or obvious raw machine translation. |
| SEO.HEAD.OUTLINE | H2 and H3 read like the questions and topics people search for. | Headings are generic ("Introduction", "More info"). | No subheadings on long pages. |
| SEO.CONTENT.HELPFUL | Page answers the main question fully, with specifics a customer needs (price range, process, timing). | Answers partly, or buries the answer under filler. | Mostly filler, keyword lists or text written for search engines. |
| SEO.CONTENT.INTENT | Page clearly serves one intent (learn, buy, book, find a location). | Mixes two intents with a clear main one. | Unclear what the page is for. |
| SEO.CONTENT.GAPS | Every main service or product has its own page, common questions answered. | Some services only mentioned in a list. | Main services have no page, questions unanswered. |
| SEO.CONTENT.FRESH | Updated dates visible and recent on time-sensitive pages. | Dates present but over a year old on fast-changing topics. | Outdated facts, prices or years on key pages. |
| SEO.EEAT.AUTHOR | Named author with bio and relevant credentials, reviewed-by for YMYL topics. | Named author without bio. | Anonymous or "admin". |
| SEO.EEAT.ABOUT | Real people, photos, address, company details, story. | Generic about text. | No about or contact information beyond a form. |
| SEO.EEAT.EXPERIENCE | Own photos, cases, results, process from real work. | Some own material, mostly stock. | Only stock images and generic claims. |
| SEO.EEAT.AI-USE | AI-assisted content is reviewed by a named person and that is stated where readers would expect it. | No statement, content clearly reviewed. | Unreviewed AI text with errors or generic filler. |
| SEO.EEAT.YMYL | Health, money or legal content cites sources and names a qualified reviewer. | Sources cited, no reviewer. | No sources, no reviewer, advice-like claims. |
| SEO.SPAM.SCALED | Every page in a set has unique, useful content. | Some templated pages with thin unique text. | Many near-identical pages with swapped city or product names. |
| SEO.SPAM.REPUTATION | All sections fit the site's own business. | One unrelated section, clearly labelled and small. | Third-party coupon, casino or affiliate sections unrelated to the business. |
| SEO.SPAM.LINKS | Outbound links are editorial and relevant. | Some sitewide partner links without `rel` attributes. | Paid link blocks, link exchange pages. |
| SEO.CITE.FACTS | Concrete facts (prices, specs, dates, numbers) in text on key pages. | Facts only in images or PDFs. | Vague claims only ("best quality", "fast"). |
| SEO.CITE.SOURCES | Claims link to primary sources. | Sources named without links. | Strong claims with no source. |
| SEO.CITE.ORIGINAL | Original data, research, tools or a clear reference page others link to. | Occasional own insight in posts. | Nothing original, only rewrites. |
| SEO.CITE.QUOTABLE | Key statements stand alone as clear sentences. | Statements depend on context ("as said above"). | Meaning only clear from images or layout. |
| SEO.READ.STRUCTURE | Answer first, then detail, with lists and tables for steps and comparisons. | Answer present but after a long intro. | Walls of text, no structure. |
| SEO.AEO.QUESTIONS | Question headings with a direct 40 to 60 word answer below. | Questions present, answers long or indirect. | No question-led sections on informational pages. |
| SEO.AEO.FAQ | FAQ with real customer questions and short, complete answers. | FAQ exists but generic or salesy. | Keyword-stuffed FAQ or none on a site that gets many questions. |
| SEO.AEO.DEFINITIONS | Key terms defined once, clearly, on a linkable page. | Terms explained in passing. | Jargon used without explanation. |
| SEO.GEO.ENTITY | Same name, description, address and facts everywhere, with `sameAs` links. | Small differences (old address on one profile). | Conflicting names, descriptions or facts across sources. |
| SEO.GEO.COMPARE | Honest comparison page for the category, naming alternatives and when to choose them. | Comparison only with generic "others". | No comparison content, or a misleading one. |
| SEO.SXO.MATCH | Landing page delivers exactly what the snippet promised. | Delivers, but the answer is below the fold. | Snippet promises something the page does not have. |
| SEO.SXO.NEXT | Clear next step on every search landing page. | Next step only at the bottom. | Dead end. |
| SEO.LOCAL.PAGES | One page per location with unique local content, address, hours, map, schema. | Location pages with only address and map. | One page for all locations, or doorway pages per city without a location. |
